## Why

После перевода AO3-книги главы остаются на русском (файловый кэш), а название, описание, фэндомы, пейринги и теги снова показываются по-английски — переведённые метаданные либо не записываются в Room, либо затираются при повторном импорте. Параллельно просмотр библиотеки — это drill-down «один выбор → сразу список», без комбинируемых фильтров, поиска по названию фэндома/пейринга и вкладок по типам тегов; на тёмной теме поверхности фильтров должны оставаться тёмными.

## What Changes

- Сохранять и восстанавливать после перезапуска переведённые **title / summary**, **displayRu** фэндомов и пейрингов, а также русские подписи **display tags** (рейтинг, предупреждения, персонажи, доп. метки и т.д.).
- Не затирать уже сохранённые RU-поля метаданных при re-import / upsert по `remoteId`.
- Заменить (или дополнить) текущий chip→drill-down поток **экраном сборки фильтров**: сначала выбрать критерии, затем открыть список подходящих книг.
- В списках выбора фэндомов, пейрингов и тегов — **поиск** с полнотекстовым и частичным совпадением (подстрока / часть слова), case-insensitive.
- Категории тегов (персонажи, рейтинги, предупреждения, доп. метки и т.д.) — **отдельные вкладки**, а не одна куча.
- Фильтры **совмещаемы** (портальный AND между категориями; multi-select внутри категории).
- Фоны экранов фильтров берут цвета из текущей shell-темы (светлая paper / тёмная night), без «всегда светлого» фона.

## Capabilities

### New Capabilities

- (нет)

### Modified Capabilities

- `ao3-translation`: усилить требование персистентности RU-метаданных (фэндомы, пейринги, display tags) и защиту от затирания при повторном импорте; главы уже кэшируются.
- `fanfic-library`: экран сборки фильтров, поиск в справочниках, вкладки по типам тегов, комбинируемая фильтрация с сохранением фильтрации по `canonicalKey`.
- `warm-paper-theme`: явно потребовать, чтобы поверхности фильтров/библиотечного browse использовали `colorScheme` текущей shell-темы (в т.ч. тёмный фон в Night).

## Impact

- `TranslationPipeline`, `LibraryDao` / `LibraryRepository`, `ImportCoordinator` (merge RU при upsert)
- Модель `DisplayTag` / codec `displayTagsJson` (поле RU или параллельная структура)
- `feature/library` (навигация, ViewModel, новые Compose-экраны фильтров и результатов)
- Тема shell (`FandomReaderTheme` / surfaces) — без смены палитры, только соблюдение схемы на новых экранах
- Тесты: FakeTranslationProvider, unit-тесты persist метаданных и комбинированного фильтра; без live Gemini
