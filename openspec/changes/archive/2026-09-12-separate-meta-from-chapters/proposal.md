## Why

Сейчас ридер подмешивает front-matter EPUB (AO3 preface / summary, Ficbook `title.xhtml`) в список «глав»: пользователь видит описание и теги как текст «Главы 1», а настоящая первая глава сдвигается. Нужна отдельная страница метаданных (описание + все теги) и чистый старт главы 1 с сюжета.

## What Changes

- Добавить **страницу произведения** (отдельно от чтения глав): полное описание/аннотация и все доступные теги (фэндомы, пейринги и прочие теги портала, если они есть в метаданных)
- Исключить front-matter документы из spine глав ридера, чтобы **глава 1 = первая сюжетная глава**, без описания/тегов в теле главы
- Переход: список библиотеки → страница метаданных → чтение; из ридера остаётся доступ к метаданным без смешивания с индексом глав
- Оглавление и chrome «Глава N/M» считают только сюжетные главы
- Подписи в оглавлении: **осмысленное название главы**, если оно есть; иначе стабильный номер **«Глава 1»**, **«Глава 2»**… (без мусорных title вроде имени всей работы / Preface)
- При необходимости расширить парсинг/хранение display-тегов (Characters, Additional Tags, Rating и т.п.), не ломая `canonicalKey`-фильтры фэндом/пейринг

## Capabilities

### New Capabilities
- `work-meta-page`: отдельный экран/страница метаданных произведения (описание + теги) вне потока глав

### Modified Capabilities
- `immersive-reader`: spine и нумерация глав без front-matter; глава 1 — первая сюжетная глава; TOC только сюжетные главы с нормальными подписями (название или «Глава N»)
- `portal-import` (при расширении тегов): парсинг дополнительных display-тегов для показа на meta-странице без изменения правил canonical filter keys

## Impact

- `:feature:library` / `:app` — маршрут `work/{id}` (или аналог), UI метаданных, навигация list → meta → reader
- `:feature:reader` — `loadEpub` / `loadFb2`: фильтрация preface/title/summary-only; переиндексация; display-label для TOC; тесты на fixtures AO3/Ficbook
- `:source:ao3` / `:source:ficbook` / domain+Room — опционально дополнительные поля тегов для полного списка на meta-странице
- Прогресс чтения: индексы глав после исключения front-matter; нужна миграция/сброс или стабильный mapping (зафиксировать в design)
- Non-goals: смена импорта файлов с устройства, настройки API-ключей, правки pipeline перевода (уже в других changes)
