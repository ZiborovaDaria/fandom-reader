## Why

Библиотека уже умеет полки, фильтры и перевод через Gemini, но повседневный UX ломается: повторное открытие книги каждый раз заново парсит EPUB, список не помнит позицию, сортировка только по EN-title, фильтры «моргают» и плохо нажимаются, кнопка перевода мешает в ряду, часть Ficbook-книг открывается пустыми/`***`, а настройки ключей заточены только под Gemini.

## What Changes

- Кэш распарсенных глав: повторное открытие недавно просмотренной книги не перепарсивает файл с нуля (пока кэш валиден).
- Сортировка списка работ: по алфавиту (RU+EN display title), по размеру файла, по последнему просмотру (**по умолчанию**); у каждого критерия два направления.
- Восстановление позиции списка: выход из книги возвращает к той же работе в том же месте `LazyColumn`.
- Стабильные фильтры (фэндомы/пейринги/метки): убрать мерцание и сделать пункты стабильно нажимаемыми.
- Настройки перевода: слоты UI под ключи нескольких провайдеров; рабочий временный провайдер **Cursor** (чат с промптом «переведи на русский»); Gemini остаётся основным; остальные слоты без живых адаптеров до отдельного change.
- Починить извлечение текста глав Ficbook EPUB, из‑за которого читалка показывает пустоту или одни `***`.
- Кнопку «Перевести» / «Перевести заново» перенести вниз строки списка (не trailing сбоку).

## Capabilities

### New Capabilities

- (нет)

### Modified Capabilities

- `fanfic-library`: сортировки с направлениями; restore scroll к открытой работе; стабильный UX фильтров; размещение кнопки перевода внизу строки.
- `immersive-reader`: кэш парсинга глав при повторном открытии; корректное тело глав Ficbook (не пусто/`***` из‑за extract).
- `ao3-translation`: выбор живого провайдера (Gemini + временный Cursor); Fake по‑прежнему только в тестах.
- `translation-settings`: UI-слоты ключей для нескольких провайдеров + Cursor; маскирование/clear; подсказка при отсутствии ключа у выбранного провайдера.

## Impact

- UI: `LibraryScreens.kt`, `FilterBuilderScreen.kt`, `SettingsScreen.kt`, навигация library↔reader.
- Data: Room (`lastOpenedAt`, размер файла или аналог), DAO/ORDER BY, возможно DataStore предпочтений сортировки.
- Reader: `ReaderScreen` / chapter load path, `ChapterText` / Ficbook HTML extract, in-memory или disk cache распарсенных глав.
- Translation: `TranslationProvider`, `ResolvingTranslationProvider`, `GeminiSettings` → обобщённое хранилище ключей; временный `CursorProvider`; DI в `AppModule`.
- Specs: дельты для четырёх capabilities выше; не ломать `canonicalKey`-фильтры, immersive chrome, Fake-in-CI, Ficbook `title.xhtml` meta rules.
